# Implementation Plan - Fix TLazyTab / TLazyTabPage ChangeBounds Loop on Startup

## Problem Description
On application startup (and when loading forms containing `TLazyTabControl`, such as `frmSettings` or the utility scratchpad panel), LCL produces a runtime error or warning:
`TControl.ChangeBounds loop detected: TLazyTabPage Left=0, Top=0 ... NewLeft=0, NewTop=34...`

## Root Cause Analysis
1. **Conflicting Layout Strategies**:
   - `TLazyTabPage` is initialized with `Align := alClient`.
   - `TLazyTabControl` did not override `AdjustClientRect(var Rect: TRect)`. Consequently, LCL's client rectangle for child controls is `(0, 0, Width, Height)`.
   - In `TLazyTabControl.UpdatePagesLayout`, manual bounds setting was performed: `P.SetBounds(0, FHeaderHeight, Width, Height - FHeaderHeight);`.
2. **Infinite Bounds Recalculation Loop**:
   - LCL's automatic alignment system sees an `alClient` child and attempts to enforce bounds `(0, 0, Width, Height)`.
   - `TLazyTabControl`'s manual layout calls `SetBounds(0, FHeaderHeight, ...)` which conflicts with LCL's `alClient` alignment, triggering recursive `ChangeBounds` cycles until LCL's recursion guard detects the loop.
3. **Premature Layout during Streaming**:
   - When loading child `TLazyTabPage` objects from LFM files (e.g. in `TSettingsForm`), `SetParent` triggers `InternalRegisterPage` which immediately executed layout updates before all child components finished streaming (`csLoading`).

---

## Proposed Changes

### 1. `uCustomTabControl.pas`
- **Override `AdjustClientRect` in `TLazyTabControl`**:
  ```pascal
  procedure TLazyTabControl.AdjustClientRect(var Rect: TRect);
  begin
    inherited AdjustClientRect(Rect);
    Inc(Rect.Top, FHeaderHeight);
  end;
  ```
  This tells LCL's alignment manager that the client area for all `alClient` controls begins at `Y = FHeaderHeight`.
- **Refactor `TLazyTabControl.UpdatePagesLayout`**:
  - Remove manual `P.SetBounds(0, FHeaderHeight, ...)` calls.
  - Simply toggle `P.Visible := (I = FActivePageIndex)` and call `P.BringToFront` for the active page.
  - Call `ReAlign` so LCL positions and dimensions the active `alClient` page smoothly within the adjusted client area without bounds conflicts.
- **Support Component Streaming (`csLoading`)**:
  - In `InternalRegisterPage`, skip immediate layout updates if `csLoading in ComponentState`.
  - Override `Loaded` in `TLazyTabControl` to execute `UpdatePagesLayout` once after streaming finishes.
- **Update `SetHeaderHeight`**:
  - When `FHeaderHeight` changes, call `ReAlign` and `Invalidate` so LCL recalculates the adjusted client rectangle.

### 2. `README.md`
- Document the `TLazyTabControl` layout architecture and fix preventing recursive `ChangeBounds` loops across platforms (Windows, Linux, macOS).
