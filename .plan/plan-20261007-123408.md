# Plan: Custom Dark/Light Themed Tab Control Component Architecture

## Overview
Lazarus/LCL native `TPageControl` and `TTabSheet` rely on native OS widget sets (Win32, GTK2, Cocoa) where tab strip headers, margins, borders, and background areas often retain default OS light colors or resist custom owner-drawn dark theme rendering.

To solve this cleanly, robustly, and cross-platform across Windows, Linux, and macOS, we will create a dedicated, fully customized and styled Tab Control suite:
- **`TLazyTabPage`**: A clean, custom panel/container for tab content (`TCustomControl` / `TWinControl`).
- **`TLazyTabControl`**: A custom multi-page container featuring:
  - Sleek top header tab bar (with configurable height, e.g. 34–36px)
  - Dark-first & Light mode palette awareness (`tkDark` / `tkLight`)
  - Active tab bottom indicator highlight line (accent blue / glowing indicator)
  - Hover highlights and smooth active tab transition
  - Tab close/pin action buttons support (optional for workspace/editor tabs)
  - Clean client area automatically hosting and displaying the selected `TLazyTabPage`
  - Cross-platform LCL rendering using pure LCL `Canvas` operations with DoubleBuffering and DPI scaling awareness.

## Proposed Changes

### 1. Create `uCustomTabControl.pas`
Create a reusable unit containing:
- **`TLazyTabPage`** (descendant of `TCustomControl`):
  - Represents a single page / tab sheet.
  - Properties: `Caption: string`, `ImageIndex: Integer`, `CanClose: Boolean`, `BadgeText: string`.
  - Automatically hidden/shown by its parent `TLazyTabControl`.
- **`TLazyTabControl`** (descendant of `TCustomControl`):
  - Maintains `FActivePageIndex: Integer`, list of `FPages: TFPList / TList`.
  - Methods: `AddPage(const ACaption: string): TLazyTabPage`, `RemovePage(APage: TLazyTabPage)`, `SelectPage(AIndex: Integer)`.
  - Event: `OnChange: TNotifyEvent`, `OnPageClose: TNotifyEvent`.
  - Sleek, modern drawing logic:
    - Tab bar header background using `P.HeaderBg` or `P.Surface`.
    - Tab buttons with crisp modern typography (`Segoe UI`, 9pt), icon/badge support.
    - Active tab visual styling: elevated background (`P.Surface`), subtle side dividers (`P.Border`), crisp bottom accent highlight bar (`P.Accent`, 2px thick).
    - Inactive tabs with clean muted text (`P.TextMuted`) transitioning to highlighted hover states.
    - Page container area filled with `P.Surface` or `P.Background`.
    - Dynamic tab clicking and hit-testing in `MouseDown` / `MouseMove` / `MouseLeave`.
  - Method: `ApplyTheme(ATheme: TThemeKind)` to sync with the application theme.

### 2. Refactor `frmSettings` (`frmSettings.pas` and `frmSettings.lfm`)
- Replace the legacy native `PageControl1: TPageControl` and `TTabSheet` objects with `TLazyTabControl` and `TLazyTabPage`:
  - `tabProvider: TLazyTabPage` ('AI Provider & Model')
  - `tabAgent: TLazyTabPage` ('Agent Behavior')
  - `tabWorkspace: TLazyTabPage` ('Workspace')
- Update visual layout and event hookups in `frmSettings.pas` and `frmSettings.lfm`.
- Remove native `TPageControl` dependencies in `frmSettings`.

---

### 3. Refactor Main Window Utility Dock Panel (`mainunit.pas`)
- Replace `FPageControlUtility: TPageControl` and `FTabSheetBlank: TTabSheet` with `TLazyTabControl` and `TLazyTabPage`.
- In `TForm1.ApplyTheme`:
  - Call `FPageControlUtility.ApplyTheme(FState.Theme)`.
- Enable dynamic creation of additional utility tabs (e.g. Workspace Scratchpad, System Output, Quick Notes) with full dark theme consistency.

## Verification Plan

### Test Scenarios
1. **Settings Dialog**:
   - Open Settings dialog via `Workspace -> Settings...` or Toolbar.
   - Verify tab header bar renders crisp dark background, muted text for inactive tabs, bright active tab with accent indicator line.
   - Click between *AI Provider & Model*, *Agent Behavior*, and *Workspace* tabs; verify smooth switching of page content.
   - Switch theme between Dark and Light mode and verify both themes render with contrast and modern styling.
2. **Main Utility Dock Panel**:
   - Verify Utility panel in the right corner hosts the `TLazyTabControl` with *Workspace Scratchpad*.
   - Detach the Utility dock panel to a floating window across screens and verify the custom tab control redraws crisply.
3. **Cross-Platform Compatibility**:
   - Verify pure Canvas LCL drawing runs without Win32-specific APIs to guarantee smooth execution on Linux and macOS.
