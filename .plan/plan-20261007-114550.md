# Implementation Plan: Dark & Modern Styling for Tab Controls and Tab Pages

## Problem Description
In the application, `TPageControl` and `TTabSheet` instances (such as `PageControl1` in `frmSettings` and `FPageControlUtility` / `FTabSheetBlank` in `mainunit`) do not properly respect the dark theme across all platforms (Windows, Linux, macOS). Under default LCL native themes on Windows and other OSes, standard `TPageControl` headers and tab bodies remain system-gray/white or ignore custom dark palettes without explicit styling, owner-drawing, or background child styling. Additionally, child controls inside tab pages (e.g. text edits, labels, combo boxes) in dialogs like `frmSettings` need consistent theme application.

## User Review Required
> [!IMPORTANT]
> - `TPageControl` tab strip drawing will support owner-drawn tabs (`OwnerDraw := True` / `OnDrawTab`) or custom themed rendering via `uTheme.pas` helper functions (`StylePageControl` and `DrawThemedTab`) so that active/inactive tab headers, borders, and text colors blend smoothly with the modern dark/light themes.
> - Custom owner-drawn tabs will maintain high contrast across Windows, Linux, and macOS.

## Proposed Changes

### 1. `uTheme.pas` — PageControl & Tab Theming Helpers
- Add reusable styling helpers for `TPageControl`:
  - `procedure StylePageControl(APageControl: TPageControl; ATheme: TThemeKind);`
  - `procedure DrawThemedTab(APageControl: TPageControl; ATabIndex: Integer; const ARect: TRect; AActive: Boolean; ATheme: TThemeKind);`
  - `procedure ApplyControlTheme(AControl: TControl; ATheme: TThemeKind);` (recursive/comprehensive styling for controls like `TEdit`, `TLabel`, `TButton`, `TComboBox`, `TMemo`, and `TTabSheet` within tab sheets).
- In `DrawThemedTab`:
  - Draw tab header backgrounds using `P.Surface` for inactive tabs and `P.AccentActive` / `P.SurfaceAlt` with bottom accent highlight for active tab.
  - Draw tab title text in `P.Text` (or `P.AccentText`/`P.Accent` for active) with crisp anti-aliased font styling (`Segoe UI`, modern default font).
  - Draw clean boundary dividers between tabs using `P.Border`.

### 2. `frmSettings.pas` / `frmSettings.lfm` — Settings Dialog Tab Page & Control Theming
- Update `TSettingsForm`:
  - Hook `PageControl1.OwnerDraw := True` and assign `OnDrawTab := @PageControl1DrawTab`.
  - In `TSettingsForm.ApplyTheme(ATheme: TThemeKind)`:
    - Call `StylePageControl(PageControl1, ATheme)`.
    - Apply background/foreground colors to `PageControl1` and all tab sheets (`tabProvider`, `tabAgent`, `tabWorkspace`).
    - Style all inputs and combos: `cboProvider`, `edtApiKey`, `edtBaseUrl`, `edtModel`, `edtTemp`, `edtMaxTokens`, `edtMaxSteps`, `edtWorkspaceRoot`, `edtWorkspaceName`.
    - Style all labels: `lblProvider`, `lblApiKey`, `lblBaseUrl`, `lblModel`, `lblNotice`, `lblTemp`, `lblMaxTokens`, `lblMaxSteps`, `lblWorkspaceRoot`, `lblWorkspaceName`.
    - Re-style `cboProvider` with `StyleComboBox(cboProvider, ATheme)` and attach `StyleComboBoxDrawItem`.
    - Invalidate the `PageControl1` so tabs immediately re-render in the new theme.

### 3. `mainunit.pas` — Utility PageControl & Tab Styling
- In `TForm1.FormCreate`:
  - Configure `FPageControlUtility.OwnerDraw := True` and attach an `OnDrawTab` event handler (`PageControlUtilityDrawTab`).
- In `TForm1.ApplyAllThemes`:
  - Call `StylePageControl(FPageControlUtility, FState.Theme)`.
  - Set `FTabSheetBlank.Color := P.Surface`.
  - Re-paint / invalidate `FPageControlUtility`.

### 4. `README.md`
- Update the documentation to reflect complete dark mode support for tab pages, tab strips, and child tab controls across all workspace panels and settings dialogs.

## Verification Plan

### Automated / Diagnostic Checks
- Run diagnostics to ensure clean compilation of `lazycodingagent.lpi` with no syntax or type errors.

### Manual Verification
1. Launch the application in dark mode (default):
   - Check the right-corner Utility / Scratchpad tab sheet header and body: confirm dark background (`#1E1E24`), dark tab strip, and high-contrast text.
2. Open Settings Dialog (`Settings...`):
   - Check tabs (`AI Provider & Model`, `Agent Behavior`, `Workspace`): confirm dark tab bar, active tab highlight, dark input boxes (`#26262E`), readable labels, and themed combo dropdowns.
   - Switch between tabs and ensure smooth rendering without white flashing or native gray borders.
3. Toggle Light / Dark Mode (`View > Toggle Light / Dark Theme`):
   - Verify all tab pages and tab headers switch between dark and clean light themes immediately.
