# Implementation Plan: Vertical Alignment & Margins for Dropdown Selectors Beside Buttons

## Problem Summary
In toolbars and action bars where `TComboBox` dropdowns and `TButton` components are placed on the same horizontal line, a visual misalignment occurs:
- `TButton` components typically stretch or have a full toolbar height (e.g. `Height = 40` in `pnlToolbar` or `Height = 38` in `FComposerFooter`).
- `TComboBox` components have a fixed standard height (around 22-26px, e.g. `ItemHeight = 22` / `Height = 23`).
- When controls are aligned (`Align = alRight` or `Align = alLeft`) without explicit top margins or vertical centering containers, the dropdowns cling to the top (`Top = 0`), creating an awkward top-heavy misalignment next to the full-height or taller buttons.

## Proposed Solution & Architecture

### 1. Main Toolbar (`mainunit.lfm` / `mainunit.pas`)
In `pnlToolbar` (Height: 40):
- **Option A (LCL Alignment & Margins - Recommended)**:
  - Enable `BorderSpacing.Top`, `BorderSpacing.Bottom`, `BorderSpacing.Right` on `cbMode` and `cbModel`.
  - Specifically: Set `BorderSpacing.Top = 7`, `BorderSpacing.Bottom = 7`, `BorderSpacing.Right = 6` (or `8`) on `cbMode` and `cbModel` so they are vertically centered in the 40px toolbar (40px - 26px dropdown ≈ 14px total margin -> 7px top & 7px bottom) and have comfortable spacing between each other and the theme button.
  - Also ensure `btnToggleTheme` has appropriate margins or alignment so the entire toolbar looks polished, modern, and cohesive.

### 2. Chat Composer Footer Bar (`uChatPanel.pas`)
In `FComposerFooter` (Height: 38):
- Currently, `FModeCombo` (`Align = alLeft`), `FModelCombo` (`Align = alRight`), and `FSendBtn` (`Align = alRight`) are placed directly in `FComposerFooter`.
- Dropdown height is ~24-26px while `FComposerFooter` is 38px.
- Set `BorderSpacing.Top := 5`, `BorderSpacing.Bottom := 5`, `BorderSpacing.Right := 6`, `BorderSpacing.Left := 2` on `FModeCombo` and `FModelCombo`.
- Set `BorderSpacing.Top := 3`, `BorderSpacing.Bottom := 3`, `BorderSpacing.Right := 2` on `FSendBtn` (or 32px height button with 3px margins for a sleek pill-like card action button).
- This ensures all controls in the chat card footer are cleanly vertically centered and properly separated.

### 3. Documentation & Verification
- Update `README.md` to document the improved visual alignment, spacing, and modern UI refinements for dropdown selectors and buttons across platforms.
- Ensure cross-platform compatibility (Windows, Linux GTK2/Qt, macOS Cocoa) by using standard LCL `BorderSpacing` properties rather than hardcoded pixel hacks.

1. **Update `mainunit.lfm`**:
   - Add `BorderSpacing.Top = 7`, `BorderSpacing.Bottom = 7`, `BorderSpacing.Right = 8` to `cbMode` and `cbModel`.
   - Add `BorderSpacing.Right = 6`, `BorderSpacing.Top = 4`, `BorderSpacing.Bottom = 4` to `btnToggleTheme` and toolbar buttons if needed for consistent modern pill styling.

   - In `TChatPanel.Create`, configure `BorderSpacing` on `FModeCombo`, `FModelCombo`, and `FSendBtn`.
   - Ensure `FComposerFooter` height and spacing balance evenly with the composer card.
