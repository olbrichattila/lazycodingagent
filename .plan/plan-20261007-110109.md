# Implementation Plan: Detachable Blank TabPage Panel in Right Corner

## Overview
Add a new dockable, detachable panel at the far right corner of the main workspace containing a modern blank `TPageControl` with a blank `TTabSheet` (TabPage). By default, this panel starts **invisible** (hidden) and can be toggled via the `Window > Panels` menu or dynamically detached into an independent floating window like all other panels.

---

## 1. Type & Identification Updates (`uAppTypes.pas`)
- Update `TPanelId` enum to include `piUtility` (or `piRightTab` / `piExtra`):
  ```pascal
  TPanelId = (piNavigation, piChat, piReserved, piUtility);
  ```
- Update `PanelCaption(AId: TPanelId)` to support the new panel:
  ```pascal
  piUtility: Result := 'Utility Panel'; // or 'Workspace Tools / Blank Tab'
  ```

---

## 2. Workspace State & Persistence (`uWorkspaceState.pas`)
- In `TWorkspaceState.ResetLayout`:
  - Ensure the default visibility for `piUtility` is `False` (`Visible := False`).
  - Active panels by default: `piNavigation` and `piChat` (or `piReserved` if configured, while `piUtility` is hidden/invisible).
  - Configure default floating window dimensions (e.g. `Width := 400`, `Height := 500`).
- Persistence (`Load` / `Save`):
  - Because `Load` and `Save` loop from `Low(TPanelId)` to `High(TPanelId)`, `piUtility` state (Visible, Floating, Coordinates) will automatically be saved and loaded from INI (`[Panel_3]`).

---

## 3. Visual Designer & Form Layout (`mainunit.lfm` & `mainunit.pas`)
### Form Definition (`mainunit.lfm`)
- Add a new right-aligned host panel `pnlUtilityHost` inside `pnlMainContainer` (Align = `alRight`, BevelOuter = `bvNone`, initial Width = e.g., 280).
- Add an accompanying splitter `splUtility` (Align = `alRight`, ResizeAnchor = `akRight`, MinSize = 160).
- Position `pnlUtilityHost` and `splUtility` at the rightmost edge of `pnlMainContainer` (to the right of `pnlReservedHost` / `pnlChatHost`).

### Code Integration (`mainunit.pas`)
- Add fields to `TForm1`:
  - `pnlUtilityHost: TPanel;`
  - `splUtility: TSplitter;`
  - `FDockUtility: TDockPanel;`
  - `FPageControlUtility: TPageControl;`
  - `FTabSheetBlank: TTabSheet;`
- In `InitWorkspaceSubControls`:
  - Instantiate `FDockUtility := TDockPanel.Create(pnlUtilityHost)`.
  - Configure `FDockUtility.Configure(piUtility, PanelCaption(piUtility), @DockPanelAction)`.
  - Instantiate `FPageControlUtility := TPageControl.Create(FDockUtility)`.
  - Configure `FPageControlUtility` with `Align := alClient`.
  - Add a blank tab sheet: `FTabSheetBlank := FPageControlUtility.AddTabSheet; FTabSheetBlank.Caption := 'Blank Tab';`.
  - Set `FDockUtility.Content := FPageControlUtility`.
- In `StateChanged`:
  - Handle docking / floating / hiding for `piUtility` matching the existing pattern:
    - If not visible -> hide `pnlUtilityHost`, `splUtility`, and floating form if detached.
    - If floating -> hide host & splitter, call `FDockUtility.DetachToWindow(L, T, W, H)`.
    - If docked & visible -> `FDockUtility.AttachToHost(pnlUtilityHost)`, set `pnlUtilityHost.Visible := True` and `splUtility.Visible := True`.
- In `ApplyAllThemes`:
  - Style `pnlUtilityHost`, `splUtility`, `FDockUtility`, and `FPageControlUtility` according to `FState.Theme` palette tokens (`Surface`, `Background`, `SplitterColor`, `Text`).

## Verification & Acceptance Checklist
1. **Initial State**: Application launches with the right corner panel hidden (invisible) by default.
2. **Toggle Visibility**: Navigating to `Window > Panels > Utility Panel` toggles the panel visible/invisible.
3. **Detachable Floating Window**:
   - Clicking Detach icon or `Window > Detach Utility Panel to Window` opens an independent floating window with the TabPage.
   - Detached window can be moved across monitors on Windows, Linux, and macOS.
   - Clicking Close / Redock returns the panel back into the right corner host panel.
4. **Theme Consistency**: Correctly transitions between Dark and Light mode.
5. **Clean Compilation**: Verified with FPC / Lazarus compiler without warnings or breakage.
