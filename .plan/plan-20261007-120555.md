# Implementation Plan: Fix TPageControl `OnDrawTab` Identifier Error

## Problem Statement
Compiling `lazycodingagent.lpi` results in compiler error:
```
frmSettings.pas(101,16) Error: identifier idents no member "OnDrawTab"
```
In Free Pascal / Lazarus LCL, `TPageControl` and `TCustomTabControl` (defined in `ComCtrls`) do not have an `OnDrawTab` or `OwnerDraw` property in standard LCL (unlike Delphi's VCL `TTabControl`). Additionally, `mainunit.pas` has the same reference (`FPageControlUtility.OnDrawTab := @PageControlUtilityDrawTab;` and `FPageControlUtility.OwnerDraw := True;`).

## Proposed Changes

### 1. `frmSettings.pas`
- Remove `PageControl1.OwnerDraw := True;` and `PageControl1.OnDrawTab := @PageControl1DrawTab;` in `FormCreate`.
- Remove declaration and implementation of `PageControl1DrawTab(Control: TCustomTabControl; TabIndex: Integer; const Rect: TRect; TabActive: Boolean);`.
- In `ApplyTheme`: `StylePageControl(PageControl1, ATheme);` already applies background, font colors, and styles across pages.

### 2. `mainunit.pas`
- Remove `FPageControlUtility.OwnerDraw := True;` and `FPageControlUtility.OnDrawTab := @PageControlUtilityDrawTab;` in `FormCreate`.
- Remove declaration and implementation of `PageControlUtilityDrawTab(Control: TCustomTabControl; TabIndex: Integer; const Rect: TRect; Active: Boolean);`.

### 3. `uTheme.pas`
- Clean up `StylePageControl` to remove invalid `APageControl.OwnerDraw := True;` assignment.
- Remove or deprecate unused `DrawThemedTab` function if not needed or preserve if used elsewhere.

## Verification
- Run compiler build diagnostic for `lazycodingagent.lpi`.
- Ensure clean build without errors on Windows/Linux/macOS LCL targets.
